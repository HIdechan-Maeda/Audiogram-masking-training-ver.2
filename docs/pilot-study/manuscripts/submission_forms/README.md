# 投稿様式（医学検査 / S1M）

公式PDFは日臨技HPから取得済み（令和対応版）。

| ファイル | 用途 |
|----------|------|
| `sheet_1_誓約書同意書.pdf` | 様式1（共著者署名が必要） |
| `sheet_1_記入用ドラフト.docx` | 様式1への転記用下書き |
| `sheet_1-2_投稿承諾書.pdf` | 連名著者なしの場合のみ（本論文は不要） |
| `sheet_2_利益相反申告書.pdf` | 様式2 |
| `sheet_2_記入用ドラフト.docx` | 様式2への転記用下書き |
| `s1m_manual.pdf` | S1M操作マニュアル |
| `contribution.pdf` | 論文作成投稿要領 |
| `JAMT_template_202606.docx` | 公式Wordテンプレート |

## 著者記入が必要なこと
1. 様式1 PDFに表題・氏名を転記し，著者4名が自筆署名
2. 様式2 PDFに①〜⑨を「無」で転記し，筆頭著者が自筆署名（開発関与の開示は本文末尾と一致）
3. 英文要旨の最終校閲証明を用意
4. S1M（https://mc.manuscriptcentral.com/jamt）へアップロード

論文表題（転記用）：
年齢・性別・聴力像パターンに応じた教育用オージオグラム自動生成システムの開発と出力規則の検証
