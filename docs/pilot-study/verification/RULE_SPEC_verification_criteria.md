# オージオグラム自動生成・検証正解表（合否基準）

**位置づけ:** 本表が検証の「正解」である。生成コードの実装を見て合格条件を後付けしない。  
**検証の本体:** 本表 ＋ 独立チェック関数／検証スクリプト ＋ 著者確認。  
**GPTの位置づけ:** 補助的コードレビュー／反例候補の列挙であり、独立検証ではない。

- 版: 2026-08-18（AOM: 伝音／混合の教育用分岐、最小ABG床をOMEと同一。OMEより大きいABGは非要求）
- 対象システム: AudioScope EDU オージオグラム自動生成
- 単位: 原則「1生成例（左右の気導・骨導閾値セット）」

---

## 0．共通前提（正式ID）

| ID | 項目 | 基準 |
|----|------|------|
| P1 | 気導周波数 | 左右とも 0.125, 0.25, 0.5, 1, 2, 4, 8 kHz |
| P2 | 骨導周波数 | 左右とも 0.25, 0.5, 1, 2, 4 kHz |
| P3 | 数値／SO | 閾値は数値、または正規のSO表現。NaN・Infinity・空文字は不適合。同一点の数値とSO二重登録は不適合 |
| P4 | 上下限 | 下表の教育用上下限内（数値点のみ）。**主合否（G4）**。境界値（min/max一致）は適合、範囲外は不適合 |
| P5 | 程度 | 受理値は 0,1,2,3。範囲外のエラー仕様は未定義（主合否にしない） |
| P6 | 一側性・患側 | **主合否はメタ整合のみ**（指定患側と評価対象の一致）。数値的な「一側差必須」は主合否にしない（補助観測可）。AOM一側率も主合否にしない |
| P7 | 同一入力再出力 | 年齢・性別・疾患・程度・患側（指定時）・seed が同一なら、左右の気導・骨導**数値**が完全一致（主合否）。SOフラグ・メタの一致は補助確認 |

### P4．周波数別上下限（凍結）

| 周波数 | AC min | AC max | BC min | BC max |
|--------|--------|--------|--------|--------|
| 0.125 kHz | 5 | 70 | — | — |
| 0.25 kHz | 5 | 90 | 5 | 60 |
| 0.5 kHz | 5 | 110 | 5 | 65 |
| 1 kHz | 0 | 110 | 0 | 70 |
| 2 kHz | 0 | 110 | 0 | 70 |
| 4 kHz | −5 | 110 | −5 | 65 |
| 8 kHz | −5 | 100 | — | — |

### SO・欠損の報告（全規則共通）

各規則で次を分けて数える: 評価対象例数／適合／不適合／**判定不能**（必要点がSO・欠損）。判定不能を分母から黙って除外して適合率を上げない。

### 疾患×程度の受理マトリクス（凍結）

凡例: ○=生成可かつ当該規則の対象 / △=生成可だが一部規則は対象外 / —=非対象

| プロファイル | 程度0 | 程度1–3 | 注 |
|--------------|-------|---------|-----|
| Normal | ○（N1） | △（生成可・N1対象。教育上は0推奨） | 程度で聴力像はほぼ変わらない |
| SNHL_Age / NoiseNotch | ○ | ○ | **両側**。S1・S2は**左右両耳** |
| SNHL_Sudden / Mumps / Meniere | ○ | ○ | **一側**。S1は患側のみ。乱択UIではsev0を1へ補正しうる |
| CHL_* | ○ | ○ | **C1は程度0も含む**（程度0=追加depthなしだが最小ABG床は維持。ABG=0ではない） |
| CHL_Otosclerosis × Carhart | 付与しない | O1/O2 | sev≥1のみ |

## 2．感音難聴（SNHL系）

| ID | 規則 | 合格条件 | 分母 |
|----|------|----------|------|
| S1 | 気骨導関係 | 評価耳で数値BC点について **BC ≤ AC+5 dB**。評価可能BC=0は不適合 | 下記「評価耳」 |
| S2 | C5-dip | 程度≥1の NoiseNotch で **左右とも** AC(4k) ≥ AC(2k)+**10** かつ AC(4k) ≥ AC(8k)+**10**（Colesらを参考にした著者設定。Coles基準そのものではない） | 程度≥1。片耳でも不足・欠損なら不適合 |
| S3 | 突発一側差 | 程度≥1で病側−対側の mean AC(0.5,1,2 kHz) ≥ **30 dB**（軽度も含む教育用床。焦点確認は程度2でも可） | 3周波がすべて数値の試行のみ |
| S3b | ムンプス床 | 程度≥1で病側 mean AC(0.5,1,2) ≥ **70 dB** かつ 一側差 ≥ **55 dB**（軽度は実質用いず高度寄り） | 程度≥1 |
| S4 | 程度の非減少 | 下記「S4定義」 | 組合せセル |

**評価耳（凍結）**
- 一側性（Sudden / Mumps / Meniere / Ossicular、および患側メタ付きAOM）: **meta.affectedSide**
- 両側性（Age / NoiseNotch / OME / Otosclerosis 等、患側メタなし）: **左右両耳**

### S4定義（凍結）

- **1セル:** 疾患（Normal以外）× 年齢群 × 性別 × seed
- **患側:** 一側性プロファイルでは検証時に **患側を固定**（例: R）。程度変更で患側が入れ替わる比較は不合格
- **程度系列:** 0→1→2→3（同一seed）
- **評価指標:**
  - 共通: 病側（固定）の mean AC(0.5, 1, 2 kHz) が各段階で非減少（同値は合格）
  - CHL追加: 病側の mean ABG(0.5, 1 kHz) も同様に非減少
- **全点SO等で mean が null:** **不適合**（判定不能を合格にしない）

## 3．伝音難聴（CHL系）・最小ABG

| プロファイル | 周波数別最小ABG (dB) |
|--------------|----------------------|
| CHL_OME | 0.25:10, 0.5:15, 1:15, **2:8** |
| CHL_AOM | 0.25:10, 0.5:15, 1:15, **2:8**（OMEと同一床。OMEより大きいことは要求しない） |
| CHL_Otosclerosis | 0.25:10, 0.5:15, 1:15, 2:5 |
| CHL_OssicularDiscontinuity | 0.25:20, 0.5:25, 1:25, 2:20, 4:15 |

| ID | 規則 | 合格条件 |
|----|------|----------|
| C1 | 最小ABG | 上表の全指定周波数で ABG ≥ 最小値。**程度0も含む**。評価耳は S1 と同じ規則（一側=患側、両側=左右） |
| C2 | AOM混合型 | 程度≥1かつ **meta.aomMixedApplied=true** のとき、患側 BC(4 kHz) > BC(0.5 kHz)、かつ数値BCについて BC ≤ AC+5。付与率は教育用 **約50%**（0.40–0.60なら記述として妥当）。臨床発生率の再現ではない |

注（5 dB丸め）: AC・BCが5の倍数ならABGも5の倍数。OMEの「2 kHz ≥8」は、**実現可能な数値では実質 ≥10** と同値。仕様上の名義値は8のまま（著者設定）。将来名義を10に揃えてもよい。

## 4．耳硬化症・Carhart様変化

| ID | 規則 | 合格条件 | 分母 |
|----|------|----------|------|
| O1 | 付与率 | 期待 0.8。観測率が **0.70–0.90（焦点200では140–180件）** なら合格。seed集合は検証前固定。臨床的妥当性とは別 | 程度≥1。個例の有無は不適合にしない |
| O2 | 幾何 | BC2>BC1 かつ BC2>BC4 かつ BC2−mean(BC1,BC4)≥5 | **meta.carhartApplied=true の例のみ**。true総数／適合／不適合／判定不能を併記 |

## 5．丸め・上下限・条件反映・再現

| ID | 規則 | 合格条件 |
|----|------|----------|
| R1 | 5 dB丸め | 数値閾値はすべて5の倍数（点単位・例単位を併記可） |
| R4 | 周波数別上下限（P4） | 数値ACは LIMITS_AC、数値BCは LIMITS_BC の閉区間内。**上限一致・下限一致は適合。上限超過・下限未満は不適合**。症例単位・点単位を併記可 |
| R2 | 条件反映 | 指定の年齢群・性別・疾患・程度がメタに一致（**数値への効果は別規則**。年齢効果T1等） |
| R3 | 同一入力再出力 | 同一入力で2回生成し、左右AC/BC数値が完全一致 |

---

## 6．主合否にしないもの

- 臨床的妥当性・教育効果・他検査
- 突発／ムンプスのSO付与率、AOM一側率（記述・付録）
- **AOMのABGがOMEより大きいこと**（大小関係は固定しない。床は同一）
- GPTレビューそのもの
- 「70歳代の方が悪い」等の効果量（別途T1等で確認する場合は本稿の記述統計／付録）

---

## 7．報告の二段階（推奨）

決定論的規則（N1,S1,S2,S3,C1,C2,O2,R1,R2,R3,**R4**）:
1. 点単位: 適合点数／評価可能点数  
2. 例単位: 全点適合例数／評価対象例数（1点違反で例不適合）

O1は集団の付与率のみ。O2は付与例が分母。
