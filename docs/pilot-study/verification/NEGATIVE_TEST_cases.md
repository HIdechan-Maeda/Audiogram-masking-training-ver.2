# 異常系テスト（意図的異常挿入）— 著者事前定義一覧

**誰が:** 著者  
**何を:** 正解表（`RULE_SPEC`）に基づく規則違反データを検証器へ入力  
**しないこと:** 生成プログラム本体の無作為書き換え、AI任せの破壊、古典的ソースコード mutation  

実行: `npm run verify:audiogram:mutations`

---
